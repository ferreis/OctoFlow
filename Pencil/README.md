# Pencil - Designs do OctoFlow

Arquivos prontos para abrir no Pencil:

- `app.pen`: arquivo principal com todas as telas lado a lado.
- `login.pen`: tela de login.
- `dashboard.pen`: tela de dashboard operacional.
- `tasks.pen`: tela de tarefas (filtros, lista e paginação).
- `profile.pen`: tela de perfil (GitHub, tema e acessibilidade).

## Ordem sugerida de uso

1. Abra `app.pen` para ver o fluxo completo.
2. Abra arquivos individuais quando quiser editar uma tela isolada.

## Escopo atual dos designs

- Estrutura visual das telas principais do Host App.
- Componentização visual por blocos (cards, header, filtros, lista e seções).
- Base pronta para evoluir para design system dedicado.
